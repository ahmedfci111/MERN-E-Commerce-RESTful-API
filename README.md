# E-Commerce RESTful API

A complete E-Commerce Backend API built with the MERN stack backend technologies (Node.js, Express.js, MongoDB).

## Features

- User Authentication & Authorization (JWT)
- Role-Based Access Control (Admin / Manager / User)
- Products, Categories, Subcategories & Brands
- Product Reviews & Ratings
- Wishlist Management
- Shopping Cart
- Coupon System
- Cash Orders
- Stripe Checkout Integration
- Order Management
- Image Upload with Multer & Sharp
- Search, Filtering, Sorting & Pagination
- Data Validation
- Global Error Handling
- Secure Password Hashing using bcrypt
- MongoDB with Mongoose

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Multer
- Sharp
- Stripe
- Express Validator

## API

RESTful API following MVC Architecture and Factory Pattern.
